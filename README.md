# 未成年人内容处置复核账本

这是一个纯后端服务基础工程，主要运行时为 Node.js 22 与 TypeScript，HTTP 层采用 Fastify。仓库已经提供健康检查、SQLite 迁移入口、自动化测试和 Docker 构建方式，领域代码可以沿现有目录继续扩展。

数据库默认写入项目目录的 `data/service.sqlite3`，也可由 `DATABASE_PATH` 指向工作目录内的其他位置。监听地址通过 `HOST` 与 `PORT` 配置，不依赖固定账号、外部数据库、缓存、消息队列或运行期网络。

## 常用命令

迁移、测试和启动命令记录在对应构建文件的脚本中；首次运行应先执行迁移，再启动 HTTP 服务。Docker 镜像在构建阶段运行基线测试，容器启动时会重复执行幂等迁移。
